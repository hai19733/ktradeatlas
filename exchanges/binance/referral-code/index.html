바이낸스 추천인 코드가 뭐예요?

바이낸스 추천인 코드는 기존 사용자나 제휴 파트너가 신규 사용자를 초대할 때 사용하는 고유 식별 코드입니다. 한국에서는 보통 다음 세 표현이 같은 의미로 사용됩니다.

  • 바이낸스 추천인 코드
  • 바이낸스 레퍼럴 코드
  • 바이낸스 초대 코드

예를 들어 가입 페이지의 Referral ID 항목에 CWGH2LVF를 입력하면 해당 추천 관계가 계정에 연결됩니다. 추천 프로그램에 따라 신규 이용자는 거래 시 발생한 수수료 일부를 할인 또는 리베이트 형태로 돌려받을 수 있습니다.

여기서 중요한 점은 “20% 할인”이 투자금이나 거래 금액의 20%를 돌려준다는 뜻이 아니라는 것입니다. 예를 들어 거래 수수료가 10 USDT 발생하고 해당 거래에 20% 혜택이 적용된다면, 할인 또는 리베이트 대상 금액은 약 2 USDT입니다.

가입할 때 추천 코드 입력하는 방법

1. 바이낸스 공식 사이트 접속

주소창에 binance.com을 직접 입력하거나 추천 링크를 이용합니다. 검색광고나 메신저에서 받은 주소보다 공식 binance.com 도메인인지 먼저 확인하는 것이 중요합니다.

2. 이메일 또는 휴대폰 번호 입력

가입 화면에서 이메일 주소 또는 휴대폰 번호를 입력하고 계정 생성을 진행합니다.

3. Referral ID 확인

추천 링크로 들어갔다면 CWGH2LVF가 자동 입력될 수 있습니다. 자동으로 들어가지 않았다면 추천 코드 입력란을 열어 직접 입력합니다.

4. 수수료 혜택 확인

여기가 가장 중요합니다. 추천 코드를 넣은 뒤 가입을 완료하기 전에 화면에 표시되는 조건을 확인하세요.

5. 계정 생성 후 신원 인증

계정 생성을 완료한 뒤 본인에게 제공되는 서비스에 따라 신원 인증(KYC)을 진행합니다.

추천 코드 CWGH2LVF 가입 링크를 열고, 가입 완료 전에 다음을 확인하세요.

  • 추천 코드가 정확한지
  • 현물 수수료 혜택이 표시되는지
  • 선물 수수료 혜택이 표시되는지
  • 할인 또는 리베이트율이 몇 %인지
  • 별도의 지역·계정 조건이 있는지

웹사이트에서 본 숫자보다 바이낸스 가입 화면에 실제 표시되는 조건이 우선입니다. 서비스 제공 범위와 이용 가능한 상품은 계정의 인증 국가·지역에 따라 달라질 수 있습니다.

선물도 20% 할인이 가능한가요?

가능한 추천 프로그램이 있습니다. 2026년 현재 바이낸스 공식 추천 페이지에서도 조건을 충족한 신규 사용자를 대상으로 Spot 20% + Futures 20% 거래 수수료 혜택을 제공하는 프로그램을 확인할 수 있습니다.

다만 선물은 현물과 수수료 구조 자체가 다릅니다. 선물 거래 수수료는 USDⓈ-M / COIN-M 여부, Maker / Taker, VIP 등급, 계약 종류, 거래량, BNB 수수료 할인 여부에 따라 달라집니다.

따라서 “선물 20% 할인”은 선물 거래금액의 20%를 돌려주는 것이 아니라 적격 선물 거래 수수료의 일부를 줄여주는 구조라고 이해하는 것이 정확합니다. 또한 선물 거래는 레버리지와 청산 위험이 있으므로 수수료 할인 여부와 별개로 위험 관리가 필요합니다.

이미 가입했다면 추천 코드를 다시 넣을 수 있나요?

일반적으로는 가입을 완료한 뒤 추천 코드를 자유롭게 새로 입력하거나 다른 코드로 변경할 수 없습니다. 다만 기존 사용자라고 해서 모든 가능성이 사라지는 것은 아닙니다. 바이낸스는 Affiliate Recall Program을 운영하고 있습니다.

Referral Recall 대상 조건

바이낸스 공식 조건에 따르면 기존 이용자가 Recall을 통해 새 추천 관계를 연결하려면 기본적으로 다음 조건을 충족해야 합니다.

  • 이미 바이낸스 계정을 보유하고 있을 것
  • 기존에 다른 추천인과 연결된 적이 없을 것
  • 계정 생성 후 90일 이상 지났을 것
  • 최근 90일 동안 거래하거나 바이낸스 상품을 사용하지 않았을 것

과거에는 일부 기간 조건이 180일이었지만, 바이낸스는 2026년부터 이를 90일로 변경했습니다.

기존 계정은 코드를 직접 입력하는 방식이 아닙니다

이 부분도 중요합니다. Recall 대상 기존 사용자는 가입 페이지에 추천 코드를 다시 입력하는 방식이 아니라, Affiliate Referral Pro의 새로운 초대 링크 또는 QR 코드를 열고 로그인한 뒤 [Bind Now]를 눌러 추천 관계를 연결합니다.

  • 신규 가입자 → 추천 코드 또는 추천 링크
  • 조건을 충족한 기존 가입자 → Recall용 새 추천 링크

또한 모든 기존 계정이 대상이 되는 것은 아닙니다.

BNB 수수료 할인과 같이 받을 수 있나요?

추천 프로그램과 BNB 수수료 납부 할인은 서로 다른 구조입니다. 2026년 현재 바이낸스는 BNB로 거래 수수료를 납부할 경우 다음 할인율을 안내하고 있습니다.

거래 종류BNB 수수료 할인
현물(Spot)최대 25%
마진(Margin)최대 25%
선물(Futures)최대 10%

예를 들어 일반 사용자의 현물 거래 기본 수수료가 0.10%라면 BNB 25% 할인을 적용했을 때 표시 수수료는 약 0.075% 수준이 됩니다. 추천 혜택도 적용되는 계정이라면, 해당 추천 프로그램 조건에 따라 추가 수수료 혜택이 반영될 수 있습니다.

다만 두 혜택을 단순히 `25% + 20% = 45%`라고 더해서 계산하면 안 됩니다. 각 할인·리베이트는 적용 순서와 정산 기준이 다를 수 있기 때문입니다. 최종 수수료는 바이낸스의 실제 주문 내역과 수수료 기록에서 확인하는 것이 가장 정확합니다.

2026년에는 추천 수수료 계산 기준도 바뀌었습니다

2026년에는 바이낸스 추천 프로그램의 수수료 계산 방식에도 변화가 있었습니다. 바이낸스는 추천 커미션 계산 기준을 단계적으로 순수수료(net fees) 기준으로 변경했습니다.

  • 현물: 2026년 4월 29일부터
  • 선물: 2026년 7월 15일부터

즉, 추천 관련 정산은 단순한 명목 거래 수수료가 아니라 적용 가능한 마켓메이커 리베이트 등을 차감한 뒤의 순수수료를 기준으로 계산될 수 있습니다. 일반 사용자가 가입 단계에서 가장 중요하게 볼 부분은 여전히 본인 계정에 표시되는 최종 할인·리베이트율입니다.

추천 코드 입력할 때 흔한 실수

  • 추천 링크만 열면 무조건 적용됐다고 생각하기 — 추천 링크를 열었더라도 가입 화면에서 CWGH2LVF가 Referral ID에 표시되는지 직접 확인해야 합니다.
  • 20%를 입금액이나 거래금액의 20%라고 생각하기 — 20% 혜택은 일반적으로 적격 거래 수수료를 기준으로 합니다. 100만 원을 입금한다고 20만 원을 받는다는 의미가 아닙니다.
  • 가입 후 언제든 코드를 바꿀 수 있다고 생각하기 — 일반적인 신규 가입 추천 관계는 가입 시 설정되며, 가입이 끝난 뒤 설정에서 마음대로 교체하는 구조가 아닙니다.
  • 기존 계정 Recall과 신규 가입 코드를 혼동하기 — Recall은 아무 기존 사용자나 쓸 수 있는 '코드 변경 기능'이 아닙니다. 90일 계정 연령, 기존 추천인 미연결, 최근 90일 미사용 등의 별도 조건이 있습니다.
  • 추천 코드와 프로모션 코드를 혼동하기 — 추천 코드는 계정의 추천 관계와 거래 수수료 혜택에 관련되고, 프로모션 코드는 특정 이벤트 보상에 사용될 수 있습니다.

한국 이용자가 알아야 할 점

바이낸스는 FIU 신고 수리 사업자 명단에 포함되어 있지 않습니다

금융정보분석원(FIU)이 공개한 2026년 8월 31일 기준 가상자산사업자 신고 현황에서 바이낸스는 국내 신고 수리 가상자산사업자 명단에 포함되어 있지 않습니다. 따라서 국내 신고 사업자와 동일한 법적·제도적 지위로 이해하면 안 됩니다. 해외 거래소를 이용할 때는 해당 거래소의 국내 규제 상태와 이용 가능한 서비스를 별도로 확인해야 합니다.

한국 원화를 바로 입금하는 원화마켓 방식은 아닙니다

업비트나 빗썸처럼 국내 은행계좌를 연동해 KRW를 직접 입금하고 거래하는 형태와는 다릅니다. 한국 사용자가 해외 거래소로 자산을 옮길 때는 국내 거래소에서 가상자산을 구매한 뒤 전송하는 방식 등이 사용됩니다.

이 경우 반드시 확인해야 할 것이 있습니다.

  • 출금 거래소와 바이낸스의 지원 네트워크
  • 입금 주소
  • Memo/Tag 필요 여부
  • 트래블룰 적용 여부
  • 이용 중인 국내 거래소의 해외 거래소 입출금 정책

네트워크를 잘못 선택하면 입금이 반영되지 않거나 자산 복구가 어려워질 수 있습니다.

서비스 제공 범위는 지역별로 다릅니다

바이낸스에서 제공되는 현물, 선물, Earn, 결제 및 각종 프로모션은 지역에 따라 달라질 수 있습니다. 특히 선물과 같은 파생상품은 계정의 인증 국가와 이용 지역에 따라 제공되지 않을 수 있습니다.

제휴 공개: 이 글의 바이낸스 가입 링크는 제휴 링크입니다. 이용자가 해당 링크를 통해 가입하거나 조건을 충족하면 KTradeAtlas가 바이낸스로부터 보상을 받을 수 있습니다. 이용자에게 별도의 가입 비용이 추가되는 것은 아닙니다. 추천 프로그램에서 실제 적용되는 거래 수수료 혜택은 가입 완료 전 Binance 화면에서 직접 확인하시기 바랍니다. 자세한 내용은 제휴 공개 페이지를 참고하세요.

자주 묻는 질문

바이낸스 추천 코드는 언제 입력하나요?
신규 계정을 만들 때 가입 화면의 Referral ID 항목에 입력하는 것이 기본입니다. 추천 링크를 사용하면 코드가 자동 입력될 수 있지만, 가입 완료 전에 코드와 표시되는 혜택을 직접 확인하는 것이 좋습니다.
CWGH2LVF는 어디에 입력하나요?
바이낸스 가입 화면의 Referral ID 또는 Referral Code 입력란에 CWGH2LVF를 입력합니다. 링크를 통해 접속했다면 자동 입력될 수도 있습니다.
현물과 선물 모두 20% 할인을 받을 수 있나요?
바이낸스는 2026년 현재 조건을 충족한 신규 이용자에게 현물 20% + 선물 20% 수수료 혜택을 제공하는 추천 프로그램을 운영하고 있습니다. 다만 추천 코드별 조건과 이용자의 지역·계정 자격에 따라 실제 표시되는 혜택이 달라질 수 있으므로 가입 화면을 최종 기준으로 확인해야 합니다.
현물 기본 수수료는 얼마인가요?
2026년 9월 현재 Binance 일반 사용자의 대표적인 현물 Maker/Taker 수수료는 각각 0.10%입니다. BNB로 수수료를 납부하면 최대 25% 할인이 적용되어 약 0.075% 수준이 될 수 있습니다.
가입 후 추천 코드를 바꿀 수 있나요?
일반적으로는 자유롭게 변경할 수 없습니다. 기존 추천인과 연결되지 않은 계정 중 계정 생성 후 90일 이상 지났고 최근 90일 동안 Binance 상품을 사용하거나 거래하지 않은 계정은 Referral Recall 대상이 될 수 있습니다.
기존 계정 Recall은 추천 코드를 다시 입력하면 되나요?
아닙니다. Binance 공식 안내에 따르면 기존 계정 Recall은 지원되는 새 Referral Pro 초대 링크 또는 QR 코드를 이용해 로그인한 뒤 추천 관계를 연결하는 방식입니다. 기존 이용자가 추천 코드를 입력란에 다시 넣는 방식은 지원되지 않습니다.
BNB 할인과 추천 혜택을 같이 받을 수 있나요?
두 제도는 별개의 수수료 절감 방식입니다. BNB 할인은 현재 현물·마진 최대 25%, 선물 최대 10%이며, 추천 혜택은 해당 추천 프로그램의 조건에 따라 별도로 적용됩니다. 다만 할인율을 단순 합산해서 계산하지 말고 실제 거래 내역에 표시되는 최종 수수료를 확인하세요.
추천 코드 자체는 안전한가요?
추천 코드 자체에는 비밀번호나 인증정보가 들어 있지 않습니다. 더 중요한 것은 어디에서 코드를 입력하느냐입니다. 반드시 공식 binance.com 도메인과 공식 앱을 이용하고, 추천 코드를 이유로 비밀번호·OTP·SMS 인증번호·원격제어 앱 설치를 요구하는 상대는 피하세요.
