빗썸에서 바이낸스로 코인 보내는 방법

빗썸에서 바이낸스로 코인을 보내려면 바이낸스에서 입금 주소를 확인한 뒤, 빗썸 출금 화면에서 같은 코인과 네트워크를 선택해 출금하면 됩니다.

빗썸은 CODE의 본인계정 확인 서비스(CODE ID Connect)를 통해 바이낸스와 계정 정보를 확인합니다. 빗썸과 바이낸스에 등록된 성명·생년월일이 일치하고, 바이낸스 입금 주소가 정상적으로 확인되면 본인 계정으로 출금할 수 있습니다.

이 글은 투자 권유가 아니라 실제 사용 절차와 위험을 설명하기 위한 정보입니다.
빠른 답변
  • 가장 중요한 건 네트워크를 양쪽에서 동일하게 맞추는 일입니다. 다르면 자산을 잃을 수 있습니다.
  • 빗썸과 바이낸스는 CODE 본인계정 확인 서비스로 연동돼 있어, 계정주(성명·생년월일)가 일치하면 별도 서류 없이 처리됩니다.
  • USDT는 TRC-20(트론)으로 보내는 게 수수료가 낮습니다. 빗썸 공지 기준 TRC-20 출금은 무료입니다.
  • 처음 보낼 때는 소액으로 테스트한 뒤 전체 금액을 보내세요.

먼저 확인할 것

  • 바이낸스 KYC(신원 인증) 완료 — 미완료면 입금 주소가 생성되지 않습니다.
  • 양쪽 계정의 계정주 정보 확인 — 빗썸과 바이낸스에 등록된 성명과 생년월일이 일치해야 합니다. 영문 이름 표기가 서로 다른 경우 계정주 확인이 실패할 수 있으므로, 출금 전에 양쪽 KYC 정보를 확인하는 것이 안전합니다.
  • 보낼 코인과 네트워크 — USDT라면 어떤 네트워크(TRC-20 등)로 받을지 미리 정해 둡니다.
  • 빗썸 출금 가능 상태 — 최초 원화 입금 후에는 72시간 동안 해당 금액 상당의 가상자산 출금이 제한됩니다. 이후 원화 입금부터는 입금 건마다 해당 원화 금액에 해당하는 가상자산에 24시간 출금 지연이 적용됩니다.

전체 과정 한눈에 보기

1. 입금 주소 확인

바이낸스에서 받을 코인과 네트워크를 고르고 입금 주소를 복사합니다.

2. 코인 준비

빗썸에서 보낼 코인(USDT·XRP·TRX 등)을 준비합니다.

3. 네트워크 맞추기

빗썸 출금 네트워크를 바이낸스와 동일하게 선택합니다.

4. 주소 입력

복사한 주소(필요 시 태그·MEMO)를 빗썸 출금 화면에 붙여넣습니다.

5. 본인계정 확인

수취 거래소를 '바이낸스'로 선택하면 계정주 일치 여부가 확인됩니다.

6. 출금 신청

휴대폰 번호 인증(카카오톡 또는 SMS)을 완료하면 출금 신청이 진행됩니다.

7. 입금 확인

바이낸스 지갑에서 도착 여부를 확인합니다.

1단계: 바이낸스 입금 주소 확인

바이낸스 앱이나 웹에서 지갑(Wallet) → 입금(Deposit)으로 들어갑니다. 받을 코인(예: USDT)을 고르고, 네트워크를 선택한 뒤 입금 주소를 복사하세요. 이때 선택한 네트워크를 기억해 둬야 합니다.

리플(XRP)처럼 태그(Tag) 또는 MEMO가 필요한 코인은 주소와 함께 태그까지 복사해 두세요. 태그를 빼먹으면 입금이 내 계정에 붙지 않고 반환 처리되거나 지연될 수 있습니다. 자세한 입금 절차는 바이낸스 공식 입출금 FAQ를 참고하세요.

2단계: 빗썸에서 출금할 코인 선택

빗썸에서 입출금 → 해당 코인 → 출금으로 이동합니다. 전송용으로는 수수료가 낮고 도착이 빠른 코인이 유리합니다.

  • USDT(TRC-20) — 빗썸의 2025년 9월 멀티체인 지원 공지에서는 Tron 네트워크 출금 수수료를 무료로 안내했습니다. 수수료 정책은 변경될 수 있으므로 실제 출금 전 화면에서 최신 수수료를 다시 확인하세요.
  • 리플(XRP) — 전송이 빠르고 수수료가 낮지만, 태그 입력이 필수입니다.
  • 트론(TRX) — 전송 속도가 빠르고 출금 수수료가 비교적 낮은 편입니다.

이더리움 네트워크의 USDT(ERC-20)나 비트코인(BTC)은 전송 수수료가 상대적으로 높을 수 있어, 단순 이동 목적에는 비효율적입니다.

3단계: 네트워크를 반드시 맞추세요

빗썸 출금 화면에서 네트워크를 고를 때 1단계에서 바이낸스가 선택한 네트워크와 동일하게 맞춥니다. 예를 들어 바이낸스에서 USDT를 TRC-20으로 받기로 했다면, 빗썸에서도 TRC-20으로 출금해야 합니다.

네트워크 불일치는 코인 유실의 가장 큰 원인입니다. 주소 형식이 같아 보여도 체인이 다르면 찾기 어려울 수 있으니, 출금 버튼을 누르기 전에 반드시 한 번 더 확인하세요. 네트워크 선택 기준은 USDT & 네트워크 가이드에서 정리해 두었습니다.

4단계: 본인계정 확인(트래블룰)

빗썸 출금 시 수취 거래소를 '바이낸스(Binance)'로 선택하면, CODE의 본인계정 확인 서비스(CODE ID Connect)를 통해 빗썸과 바이낸스의 계정주 정보가 확인됩니다. 성명·생년월일과 바이낸스 입금 주소가 모두 확인되면 별도 증빙 없이 처리됩니다. 자세한 내용은 빗썸 고객센터의 바이낸스(Binance) 입출금 이용가이드를 참고하세요.

  • 100만원 이상 — 본인 지갑 주소로만 출금할 수 있습니다. 빗썸과 바이낸스의 계정주(성명·생년월일)가 일치해야 합니다.
  • 100만원 미만 — 현재(2026년 9월) 트래블룰 정보제공 의무 대상은 아닙니다. 다만 빗썸의 출금 정책과 FDS 심사는 그대로 적용됩니다. 바이낸스는 빗썸의 본인계정 확인 서비스 대상 거래소이므로 별도의 출금주소 등록 없이 이용할 수 있습니다. 미신고 가상자산사업자로의 입출금은 금액과 관계없이 제한될 수 있습니다. 또한 100만원 미만으로 반복 출금하는 경우 비정상 출금으로 판단되어 출금 제한 등 서비스 제한이 발생할 수 있습니다.

참고: 금융위원회는 2026년 8월 트래블룰의 현행 100만원 기준을 폐지하고 정보제공 의무를 전체 거래로 확대하는 시행령 개정안을 의결했습니다. 관련 규정은 공포 후 6개월이 지난 날부터 시행될 예정입니다. 따라서 시행 이후에는 현재의 '100만원 미만 / 이상' 구분이 달라질 수 있습니다. 이 가이드는 2026년 9월 기준이며, 실제 시행 시 빗썸 정책에 맞춰 업데이트합니다.

5단계: 출금 완료 후 입금 확인

출금 수량을 입력하고 휴대폰 번호 인증(카카오톡 또는 SMS)을 완료하면 출금 신청이 진행됩니다. 완료 후 바이낸스 Spot 지갑에서 도착 여부를 확인하세요. 거래 내역의 TXID(트랜잭션 ID)를 블록체인 탐색기에서 조회하면 진행 상황을 정확히 확인할 수 있습니다.

수수료는 얼마인가요?

항목내용
출금 수수료코인·체인별로 다르며 자주 변경됩니다. 빗썸의 2025년 9월 멀티체인 지원 공지 기준 USDT는 Tron 무료·Ethereum 4 USDT였습니다. 출금 전 화면에서 최종 수수료를 확인하세요.
입금 수수료바이낸스 입금은 무료입니다. (네트워크 수수료는 보내는 쪽에서 부담)
네트워크 수수료체인별로 다릅니다. XRP·TRX는 낮은 편, BTC·ETH는 상대적으로 높습니다.

얼마나 걸리나요?

보통 수분~수십 분 안에 도착하지만, 네트워크가 혼잡하면 더 걸릴 수 있습니다. 도착 여부는 시간이 아니라 블록체인 컨펌(확정) 수를 기준으로 판단하는 게 정확합니다.

입금이 안 들어올 때

  • TXID로 확인 — 출금이 실제로 전송됐는지 블록체인 탐색기에서 먼저 확인합니다.
  • 네트워크 불일치 — 빗썸과 바이낸스가 같은 네트워크인지 다시 확인합니다.
  • 태그·MEMO 누락 — XRP 등 태그가 필요한 코인은 태그가 빠지지 않았는지 확인합니다.
  • 계정주 불일치 — 본인계정 확인에서 반려됐다면 빗썸과 바이낸스의 성명·생년월일이 같은지 확인합니다.
  • FDS 심사 — 모든 가상자산 출금은 빗썸의 이상금융거래탐지시스템(FDS) 심사를 거칩니다. 금융사고 패턴으로 탐지되면 최대 72시간 동안 출금이 제한될 수 있습니다.
  • 바이낸스 점검 여부 — 해당 코인의 입금이 일시 중단됐는지 바이낸스 공지를 확인합니다.

자세한 원인별 대응은 바이낸스 입금이 안 될 때 가이드에서 정리했습니다.

자주 묻는 질문

본인계정 확인(CODE)은 무엇인가요?
빗썸이 외부 거래소로 가상자산을 보낼 때 상대 거래소의 계정주를 확인하는 절차입니다. 빗썸과 바이낸스에 등록된 성명·생년월일과 바이낸스 입금 주소가 모두 확인되면 별도 증빙 없이 입출금이 처리됩니다. 바이낸스는 본인계정 확인 대상이라 화이트리스트 주소 등록 없이도 이용할 수 있습니다.
영문 이름이 다르면 어떻게 되나요?
빗썸과 바이낸스의 계정주 정보가 일치하지 않으면 출금 시 본인계정 확인에 실패할 수 있습니다. 실제 정보가 다른 경우에는 거래소 고객센터를 통해 먼저 수정하는 것이 안전합니다.
성명과 생년월일이 같은데 본인계정 확인이 실패하면 어떻게 하나요?
바이낸스의 입금 주소가 정확한지 먼저 확인하세요. 빗썸 공식 안내에 따르면 바이낸스 계정의 Middle Name 항목 때문에 계정 정보 확인이 실패하는 경우도 있습니다. First Name·Last Name과 생년월일이 빗썸 정보와 일치하는지 확인한 뒤 다시 시도하세요.
어떤 코인으로 보내는 게 좋나요?
수수료와 속도를 기준으로 USDT(TRC-20), 리플(XRP), 트론(TRX)이 무난합니다. 목적지에서 바로 USDT를 사용할 계획이라면 TRC-20을 우선 비교해 볼 수 있습니다. 빗썸의 2025년 9월 공지에서는 Tron 출금 수수료를 무료로 안내했지만, 실제 출금 전 최신 수수료를 확인하세요.
네트워크를 잘못 선택하면 어떻게 되나요?
자산이 잘못된 체인으로 보내져 회수하기 어려울 수 있습니다. 출금 전에 양쪽 네트워크를 반드시 일치시키고, 처음에는 소액으로 테스트하세요.
