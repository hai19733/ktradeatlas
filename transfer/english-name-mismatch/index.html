문제 해결

영문 이름 불일치로 송금이 막혔을 때: 바이낸스·업비트 이름 확인과 수정 순서

업비트에서 바이낸스 또는 OKX로 코인을 보내려는데 '계정주 확인에 실패했습니다', '이름이 일치하지 않습니다' 같은 메시지가 표시된다면, 먼저 양쪽 거래소에 등록된 성명과 생년월일을 확인해야 합니다.

계정주 확인에 실패했다고 해서 곧바로 자산이 사라졌다는 뜻은 아닙니다. 먼저 오류 문구를 확인한 뒤 성명·생년월일·입금 주소·거주지 정보 등을 순서대로 점검해야 합니다.

마지막 확인 2026.09.16 난이도 초보자 예상 읽기 시간 6분
이 글은 투자 권유가 아니라 실제 사용 절차와 위험을 설명하기 위한 정보입니다.
빠른 답변
  • 바이낸스·OKX·Bybit 등은 현재 업비트의 '계정주 확인 연동 가상자산사업자'에 포함됩니다.
  • 현재 100만원 이상 가상자산 입출금 시 양쪽 계정의 성명과 생년월일이 일치해야 합니다.
  • 이름이 다르다면 임의로 표기를 맞추기보다 실명증표에 등록된 본인 이름을 기준으로 거래소 정보를 수정하세요.
  • Binance에서 이름·생년월일이 맞는데도 실패한다면 Middle Name 입력 여부를 반드시 확인하세요.
  • 이름 수정 직후에는 계정주 확인 정보가 즉시 반영되지 않을 수 있으므로, 상태를 다시 확인한 뒤 전송하는 것이 좋습니다.

왜 이름이 다르면 송금이 막히나요?

업비트는 일부 해외 거래소와 계정주 확인 서비스를 연동하고 있습니다. 이 서비스는 업비트 계정과 상대 거래소 계정이 동일인의 것인지 확인하기 위해 다음 정보를 비교합니다.

확인 항목확인 내용
성명한글 또는 영문 이름
생년월일양쪽 계정의 생년월일
상대 거래소실제 선택한 거래소와 주소가 일치하는지
거주지일부 오류에서는 상대 거래소의 Country of Residence도 확인 필요

현재 바이낸스(Binance), OKX, Bybit, Bitget 등은 업비트의 '계정주 확인 연동 가상자산사업자'에 포함되어 있습니다. 이들 거래소와 100만원 이상 디지털 자산을 입출금할 때 계정주 확인 서비스가 적용됩니다. 전체 구조는 트래블룰 100만원 기준 총정리에서 별도로 설명했습니다.

가장 먼저 확인할 것

문제가 발생했다면 업비트와 상대 거래소의 계정 정보를 나란히 확인하세요.

확인 항목확인해야 할 내용
업비트 이름본인 실명정보와 일치하는지
바이낸스 이름본인 실명정보와 일치하는지
생년월일양쪽 거래소가 동일한지

입금 주소선택한 거래소의 실제 입금 주소가 맞는지

특히 영문명은 철자가 잘못 입력되어 있지 않은지 확인하세요.

계정주 확인에 실패하는 대표적인 경우

1. 이름이 서로 다른 경우

업비트와 상대 거래소에 등록된 성명이 서로 다르면 계정주 확인에 실패할 수 있습니다. 예를 들어 한쪽 거래소에 영문 이름이 잘못 입력되어 있거나, 실제 신분증상의 이름과 다르게 등록된 경우입니다.

중요한 것은 임의로 이름을 바꾸는 것이 아니라, 거래소의 고객확인(KYC)에 사용한 실명증표와 일치하도록 수정하는 것입니다.

2. 생년월일이 다른 경우

계정주 확인은 이름만 보는 것이 아닙니다. 업비트 공식 안내에 따르면 성명과 생년월일 정보가 모두 일치해야 정상적인 계정주 확인이 가능합니다. 이름이 정확해 보여도 계속 실패한다면 양쪽 거래소의 생년월일을 함께 확인하세요.

3. Binance에 Middle Name을 입력한 경우

이 부분은 Binance 이용자가 특히 주의해야 합니다. 업비트는 현재 공식 고객센터에서 Binance의 성명 정보에 Middle Name이 포함된 경우 계정주 확인이 불가능할 수 있다고 안내하고 있으며, First Name / Last Name을 사용하도록 안내합니다.

예를 들어 이름이 홍길동이라면 Binance에서 다음과 같이 입력하는 방식이 기준이 됩니다.

First NameMiddle NameLast Name업비트 계정주 확인
GILDONG(비움)HONG가능
GILDONGHONG확인 실패 가능

즉 한국 이름을 Middle Name으로 별도로 나누지 말고, First Name / Last Name 구조로 등록되어 있는지 확인하는 것이 중요합니다.

4. 거래소와 입금 주소가 맞지 않는 경우

계정주 확인 오류가 반드시 이름 때문인 것은 아닙니다. 업비트에서 다음과 같은 메시지가 나온다면 이름보다 주소를 먼저 확인해야 합니다.

  • 받는 사람 주소가 일치하지 않습니다.
  • 선택하신 거래소에서 확인되지 않는 입금 주소입니다.

이 경우 출금 화면에서 선택한 거래소와 실제 입력한 입금 주소가 같은 거래소의 주소인지 확인하세요.

5. Country of Residence 문제

업비트에서 '상대 거래소에 해당 출금 내역이 없습니다'라는 오류가 나온다면, 상대 거래소에 등록된 Country of Residence(거주 국가)도 확인해야 합니다. Binance에서는 Identification → Personal Information에서 거주 국가 정보를 확인할 수 있습니다.

업비트에서 이름과 생년월일 확인하는 방법

업비트 공식 안내 기준 확인 경로는 다음과 같습니다.

  • 모바일 앱 — [더보기] → [프로필 이미지 또는 닉네임] → [회원정보]
  • PC 웹 — [My] → [마이페이지] → [회원정보 수정]

여기에 등록된 성명과 생년월일을 상대 거래소 정보와 비교하세요.

바이낸스에서 이름 확인하는 방법

Binance에서는 다음 경로에서 Personal Information을 확인할 수 있습니다.

  • 모바일 앱 — [좌측 상단 메뉴] → [유저 닉네임] → [Verifications] → [Personal information]
  • PC 웹 — [Account] → [Identification] → [Personal Information]

여기에서 이름, 생년월일과 함께 필요한 경우 Country of Residence도 확인하세요.

이름이나 생년월일이 다르면 어떻게 수정하나요?

두 거래소 정보가 다르다면 실명증표와 일치하지 않는 쪽의 정보를 수정해야 합니다. 임의로 다른 거래소의 표기만 따라 입력하는 것은 권장하지 않습니다.

Binance 이름·생년월일 수정

업비트가 안내하는 Binance 수정 경로는 다음과 같습니다.

  • PC 웹 — [Support] → [Support Center] → [Name/Birthday Correction]
  • 모바일 앱 — [메뉴] → [More service] → 검색창에서 self-service 검색 → [Account] → [Name/Birthday Correction]

수정 과정에서는 Binance가 추가 본인확인 자료를 요구할 수 있습니다.

업비트 정보가 잘못된 경우

업비트에 등록된 정보 자체가 실제 본인정보와 다르다면, 업비트 고객센터의 안내에 따라 고객정보 수정 또는 고객확인 재이행 절차를 진행해야 합니다.

수정하기 전에 현재 양쪽 거래소의 Personal Information 화면을 캡처해 두면 고객센터에 문의할 때 문제를 설명하기 쉽습니다.

수정했는데 바로 계정주 확인이 안 될 때

이름이나 생년월일을 수정했다고 해서 항상 즉시 반영되는 것은 아닙니다. 업비트는 계정주 동일 여부를 정기적으로 다시 확인하며, 상대 거래소의 계정정보가 변경된 경우 계정주 확인 응답이 지연될 수 있다고 안내하고 있습니다.

따라서 수정 직후 계속 실패한다면 다음 순서로 다시 확인하세요.

1. 이름·생년월일 재확인

수정한 정보가 정상 저장됐는지 양쪽을 다시 확인합니다.

2. Binance Middle Name 확인

First Name / Last Name만 입력되어 있는지 확인합니다.

3. Country of Residence 확인

실제 거주정보와 일치하는지 확인합니다.

4. 거래소·입금 주소 확인

선택한 거래소와 주소가 일치하는지 확인합니다.

5. 재시도

일정 시간이 지난 뒤 계정주 확인을 다시 시도합니다.

6. 고객센터 문의

계속 실패하면 업비트 또는 상대 거래소 고객센터에 문의합니다.

100만원 미만이면 이름 확인을 안 해도 되나요?

2026년 9월 현재 업비트의 계정주 확인 서비스는 100만원 이상 디지털 자산 입출금에 적용됩니다. 하지만 이를 이유로 100만원 미만으로 금액을 반복해서 나눠 보내는 방식은 권장하지 않습니다.

특히 한국의 트래블룰 제도 자체가 곧 바뀝니다. 2026년 개정된 특정금융정보법 시행령에 따라 현재의 100만원 기준금액은 폐지될 예정이며, 가상자산 이전 시 정보제공 의무가 금액과 관계없이 확대될 예정입니다. 관련 개정사항은 2027년 2월 시행 예정이므로, 실제 적용 시점에는 금융위원회와 업비트 등 거래소의 최신 공지를 다시 확인하는 것이 안전합니다.

따라서 금액을 기준으로 우회하려 하기보다, 처음부터 거래소의 이름과 생년월일 정보를 정확하게 맞춰 두는 것이 좋습니다. 자세한 제도 변경 내용은 트래블룰 100만원 기준 총정리에서 확인할 수 있습니다.

이미 입금대기 상태라면

업비트에 코인을 보냈는데 입금대기 상태라면 먼저 해당 거래의 상세 상태를 확인하세요. 계정주 확인 문제인지, 입금 출처 확인이 필요한지, 주소 또는 네트워크 문제인지에 따라 처리 방법이 달라집니다.

업비트에서는 [입출금] → 해당 자산 → [입출금 내역] → [입금 내역 상세]에서 상태를 확인할 수 있습니다.

반대로 Binance로 보낸 뒤 입금이 반영되지 않는 상황이라면 바이낸스 입금이 안 될 때 가이드에서 네트워크, TXID, 입금 최소수량 등을 함께 확인하세요.

자주 묻는 질문

영문 이름이 다르면 출금 자체가 안 되나요?
100만원 이상을 계정주 확인 연동 거래소와 주고받을 때, 업비트와 상대 거래소의 성명·생년월일 정보가 일치하지 않으면 계정주 확인에 실패할 수 있습니다. 먼저 오류 메시지를 확인한 뒤 실제 이름 불일치인지, 생년월일이나 주소 문제인지 구분하세요.
대소문자나 띄어쓰기도 반드시 똑같아야 하나요?
업비트는 공식적으로 양쪽 거래소의 성명과 생년월일이 일치해야 한다고 안내하며, 영문명의 철자 오류도 주의하도록 안내하고 있습니다. 다만 공개된 공식 안내만으로 대소문자 또는 띄어쓰기 차이가 항상 실패 원인이 된다고 단정하기는 어렵습니다. 가장 안전한 방법은 양쪽 거래소 모두 본인 실명증표를 기준으로 정확한 영문명을 등록하는 것입니다.
Binance에 Middle Name을 넣으면 안 되나요?
업비트와 Binance 간 계정주 확인에서는 주의해야 합니다. 업비트 공식 안내에 따르면 Binance 성명 정보에 Middle Name을 포함하면 계정주 확인이 되지 않을 수 있으며, First Name / Last Name을 이용하도록 안내하고 있습니다.
이름을 수정했는데 왜 바로 안 되나요?
계정주 확인은 정기적으로 재확인되기 때문에, 상대 거래소의 정보 변경 직후에는 응답 대기가 발생할 수 있습니다. 먼저 변경된 개인정보가 정상적으로 저장됐는지 확인한 뒤 다시 시도하세요.
생년월일도 맞아야 하나요?
네. 업비트 계정주 확인 서비스는 성명과 생년월일을 함께 비교합니다. 이름이 같아도 생년월일이 일치하지 않으면 확인에 실패할 수 있습니다.
100만원 미만으로 나눠 보내면 되나요?
트래블룰이나 고객확인 절차를 피하기 위한 목적으로 반복 분할송금을 하는 방식은 권장하지 않습니다. 또한 100만원 기준 자체가 폐지될 예정이므로, 근본적인 해결책은 거래소에 등록된 본인정보를 정확하게 유지하는 것입니다.

공식 출처

  • 업비트 고객센터 — 계정주 동일 여부 확인에 실패했어요
