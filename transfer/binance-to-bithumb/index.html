바이낸스에서 빗썸으로 코인 보내는 방법

바이낸스에서 빗썸으로 코인을 보내려면 빗썸에서 입금 주소를 확인한 뒤, 바이낸스 출금 화면에서 같은 코인과 네트워크를 선택해 출금하면 됩니다.

바이낸스는 빗썸의 본인계정 확인 서비스(CODE ID Connect) 연동 거래소입니다. 다만 해외 거래소에서 빗썸으로 100만원 이상 입금한 경우에는 자동 반영되지 않고 '입금신청 대기' 상태가 되며, 입금 신청 후 송금 거래소의 본인정보와 지갑주소 등 증빙자료를 제출해 심사를 받아야 합니다.

빠른 답변
  • 가장 중요한 건 네트워크를 양쪽에서 동일하게 맞추는 일입니다. 빗썸 USDT 입금은 Tron·Ethereum·Kaia·Aptos 네트워크를 지원합니다.
  • 바이낸스는 빗썸의 본인계정 확인 서비스(CODE ID Connect) 연동 거래소입니다. 다만 해외 거래소에서 100만원 이상 입금하면 자동 반영되지 않고 입금신청 대기 상태가 되며, 입금 신청 후 송금 거래소 본인정보와 지갑주소 등 증빙자료를 제출해야 반영됩니다.
  • 본인계정 확인에서는 성명·생년월일 등 계정주 정보가 중요합니다. 주소 정보가 일치하지 않으면 확인에 실패할 수 있으니 입출금 주소도 정확히 확인하세요.
  • 바이낸스 성명의 Middle Name 항목에 내용이 입력되어 있으면 본인계정 확인에 실패할 수 있습니다. First Name / Last Name만 정확히 입력하고 Middle Name 항목은 비워두세요.

먼저 확인할 것

  • 양쪽 계정주 일치 — 빗썸과 바이낸스에 등록된 성명·생년월일이 동일해야 합니다. 이름 표기가 다르면 입금 반영이 지연되거나 반환될 수 있습니다.
  • 바이낸스 Middle Name 확인 — 바이낸스 성명의 Middle Name 항목에 내용이 입력되어 있으면 본인계정 확인에 실패할 수 있습니다. First Name / Last Name만 정확히 입력하고 Middle Name 항목은 비워두세요.
  • 보낼 코인과 네트워크 — 빗썸이 지원하는 네트워크를 미리 확인합니다. USDT라면 빗썸이 지원하는 네트워크(Tron·Ethereum·Kaia·Aptos) 중 하나로 받습니다.
  • 태그 필요 여부 — XRP 등은 데스티네이션 태그(Tag)가 필수입니다.
  • 바이낸스 KYC 완료 — 바이낸스에서 출금하려면 신원 인증(KYC)을 완료한 계정이어야 합니다.

전체 과정 한눈에 보기

1. 입금 주소 확인

빗썸에서 받을 코인과 네트워크를 고르고 입금 주소(필요 시 태그)를 복사합니다.

2. 코인 준비

바이낸스에서 보낼 코인(USDT·XRP·TRX 등)을 준비합니다.

3. 네트워크 맞추기

바이낸스 출금 네트워크를 빗썸과 동일하게 선택합니다.

4. 주소·태그 입력

복사한 주소와 태그를 바이낸스 출금 화면에 붙여넣습니다.

5. 출금 신청

바이낸스 인증을 완료하면 출금이 전송됩니다.

6. 입금신청 대기 · 증빙 확인

100만원 이상 해외 거래소 입금은 빗썸에서 입금신청 대기 상태가 될 수 있습니다. 입금 신청 후 송금 거래소 본인정보와 지갑주소 등 증빙자료를 제출하면 심사 후 반영됩니다.

1단계: 빗썸 입금 주소 확인

빗썸 앱이나 웹에서 입출금 → 해당 코인 → 입금으로 들어갑니다. 받을 코인을 고르고, 네트워크를 선택한 뒤 입금 주소를 복사하세요. 이때 선택한 네트워크를 기억해 둬야 합니다.

리플(XRP)처럼 데스티네이션 태그(Tag)가 필요한 코인은 주소와 함께 태그까지 복사해 두세요. 태그를 빼먹으면 입금이 내 계정에 붙지 않고 반환 처리되거나 지연될 수 있습니다. 입금 전 상태는 입출금 → 해당 코인 → 입출금 현황에서 확인할 수 있습니다.

2단계: 바이낸스에서 출금 준비

바이낸스에서 지갑 → 출금(Withdraw)으로 이동해 같은 코인을 선택합니다. 전송용으로는 수수료가 낮고 도착이 빠른 코인이 유리합니다.

  • 리플(XRP) — 전송이 빠르고 수수료가 낮지만, 데스티네이션 태그 입력이 필수입니다.
  • 트론(TRX) — 전송 속도가 빠르고 출금 수수료가 비교적 낮은 편입니다.
  • USDT — 빗썸은 USDT 입출금에 Tron·Ethereum·Kaia·Aptos 네트워크를 지원합니다. Tron(TRC-20)은 바이낸스와 빗썸이 모두 지원하는 네트워크 중 하나이므로, 실제 출금 수수료와 처리 속도를 비교한 뒤 선택할 수 있습니다.

비트코인(BTC)이나 이더리움(ETH)은 전송 수수료가 상대적으로 높고 속도가 느릴 수 있어, 단순 이동 목적에는 비효율적입니다.

3단계: 네트워크를 반드시 맞추세요

바이낸스 출금 화면에서 네트워크를 고를 때 1단계에서 빗썸이 선택한 네트워크와 동일하게 맞춥니다.

빗썸은 2026년 9월 현재 USDT 입출금에 Tron, Ethereum, Kaia, Aptos 네트워크를 지원합니다. 바이낸스에서 USDT를 보낼 때는 빗썸 입금 화면에 실제 표시되는 네트워크 중 하나를 선택하고, 바이낸스 출금 화면에서도 동일한 네트워크를 선택하세요. 빗썸 입금 화면에 표시되지 않는 네트워크로 보내면 입금이 반영되지 않거나 복구가 어려울 수 있습니다. 네트워크 선택 기준은 USDT & 네트워크 가이드를 참고하세요.

네트워크 불일치는 코인 유실의 가장 큰 원인입니다. 주소 형식이 같아 보여도 체인이 다르면 찾기 어려울 수 있으니, 출금 버튼을 누르기 전에 반드시 한 번 더 확인하세요.

4단계: 트래블룰 확인

트래블룰 절차는 금액에 따라 달라집니다. 빗썸의 입금 대기 안내는 빗썸 고객센터에서 확인할 수 있습니다.

  • 100만원 이상 — 해외 거래소인 바이낸스에서 빗썸으로 100만원 이상 입금하면 자동 반영되지 않고 '입금신청 대기' 상태가 됩니다. 입출금 내역에서 해당 건의 입금 신청을 진행하고, 송금 거래소의 본인정보와 지갑주소 등 증빙자료를 제출하면 빗썸 심사 후 반영됩니다.
  • 100만원 미만 — 현재(2026년 9월) 트래블룰 본인계정 추가 확인 대상은 아닙니다. 다만 네트워크, 입금처, 지원 여부 및 빗썸의 이상거래 모니터링 정책은 그대로 적용되므로, 미신고 가상자산사업자나 등록되지 않은 개인지갑을 통한 입금은 금액과 관계없이 반영이 제한될 수 있습니다.

참고: 금융위원회는 2026년 8월 트래블룰의 현행 100만원 기준을 폐지하고 정보제공 의무를 전체 거래로 확대하는 시행령 개정안을 의결했습니다. 관련 규정은 공포 후 6개월이 지난 날부터 시행될 예정입니다. 따라서 시행 이후에는 현재의 '100만원 미만 / 이상' 구분이 달라질 수 있습니다. 이 가이드는 2026년 9월 기준이며, 실제 시행 시 빗썸 정책에 맞춰 업데이트합니다.

5단계: 입금신청 대기 후 증빙 제출

바이낸스에서 보낸 코인이 네트워크에 도착해도, 해외 거래소에서 100만원 이상 입금한 경우 빗썸은 자동으로 반영하지 않고 '입금신청 대기' 상태로 두고 별도의 입금 신청을 요구할 수 있습니다.

반영 절차는 다음과 같습니다.

  1. 빗썸 입출금 내역에서 해당 입금 건을 확인합니다.
  2. 입금신청 대기 건을 선택해 입금 신청을 진행합니다.
  3. 입금 정보를 확인합니다.
  4. 송금 거래소(바이낸스)의 본인정보와 지갑주소 등 요구되는 증빙자료를 제출합니다.
  5. 빗썸이 심사한 뒤 입금이 반영됩니다.

한편 빗썸과 바이낸스의 본인계정 확인 서비스(CODE ID Connect)는 양쪽 계정의 소유자가 같은 사람인지를 확인하는 기능으로, 성명·생년월일 등 계정주 정보가 기준이 됩니다. 빗썸의 바이낸스 전용 안내에서는 주소 정보가 일치하지 않으면 본인계정 확인에 실패할 수 있다고 안내하고 있으므로, 입출금 주소도 정확히 확인해야 합니다.

Middle Name 주의: 바이낸스 성명의 Middle Name 항목에 내용이 입력되어 있으면 본인계정 확인에 실패할 수 있습니다. 빗썸은 First Name / Last Name을 정확히 입력하고 Middle Name 항목은 비워둘 것을 안내하고 있습니다.

수수료는 얼마인가요?

항목내용
바이낸스 출금 수수료코인·네트워크별로 다르며 자주 변경됩니다. 출금 전 바이낸스 출금 화면에서 최종 수수료를 확인하세요.
빗썸 입금 수수료일반적으로 무료입니다. 다만 일부 가상자산은 소액 입금 기준 이하일 경우 수수료가 부과될 수 있습니다.
네트워크 수수료체인별로 다릅니다. XRP·TRX는 낮은 편, BTC·ETH는 상대적으로 높습니다.

얼마나 걸리나요?

보통 수분~수십 분 안에 도착하지만, 네트워크가 혼잡하면 더 걸릴 수 있습니다. 100만원 이상 해외 거래소 입금은 블록체인 전송 이후 입금신청 대기 → 입금 신청·증빙 제출 → 심사 절차가 추가로 필요해, 입금 신청을 진행하기 전까지는 반영되지 않습니다. 도착 여부는 시간이 아니라 블록체인 컨펌(확정) 수를 기준으로 판단하는 게 정확합니다.

입금이 안 들어올 때

  • 입금신청 대기 확인 — 100만원 이상 해외 거래소 입금은 빗썸 입출금 내역 → 입금신청 대기 건 → 입금 신청을 진행해야 반영됩니다.
  • 계정주 불일치 — 바이낸스와 빗썸의 성명·생년월일이 일치하는지 확인합니다. 다르면 확인에 실패하거나 반환 절차가 필요할 수 있습니다.
  • Middle Name 확인 — 바이낸스 성명의 Middle Name 항목에 내용이 입력되어 있는지 확인합니다. 입력되어 있으면 본인계정 확인에 실패할 수 있습니다.
  • 네트워크 불일치 — 바이낸스와 빗썸이 같은 네트워크인지 다시 확인합니다. 빗썸 USDT는 Tron·Ethereum·Kaia·Aptos 네트워크를 지원합니다.
  • 태그·MEMO 누락 — XRP 등 태그가 필요한 코인은 태그가 빠지지 않았는지 확인합니다.
  • TXID 확인 — 출금이 실제로 전송됐는지 블록체인 탐색기에서 TXID(트랜잭션 해시)로 먼저 확인합니다.

블록체인에서는 전송 완료로 확인되는데 빗썸에 계속 반영되지 않는다면, TXID를 준비해 빗썸 고객센터에 문의하세요.

자주 묻는 질문

바이낸스에서 빗썸으로 100만원 이상 보내면 바로 입금되나요?
바로 반영되지 않을 수 있습니다. 빗썸은 해외 거래소에서 100만원 이상 입금된 경우 입금신청 대기 상태에서 별도의 입금 신청을 요구할 수 있습니다. 입출금 내역에서 해당 건을 선택한 뒤 송금 거래소 본인정보와 지갑주소 등 요구되는 증빙자료를 제출하면 심사 후 반영됩니다.
100만원 미만이면 트래블룰 확인 없이 바로 입금되나요?

바이낸스에 Middle Name이 있으면 어떻게 되나요?
바이낸스 성명의 Middle Name 항목에 내용이 입력되어 있으면 본인계정 확인에 실패할 수 있습니다. First Name / Last Name만 정확히 입력하고 Middle Name 항목은 비워두세요.
