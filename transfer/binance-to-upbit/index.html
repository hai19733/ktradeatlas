바이낸스에서 업비트로 코인 보내는 방법

김민준 · KTradeAtlas 편집자 국내·해외 거래소 입출금·트래블룰 절차를 공식 문서와 실제 화면으로 확인해 작성합니다.

바이낸스에서 업비트로 코인을 보내려면 업비트에서 입금 주소를 확인한 뒤, 바이낸스 출금 화면에서 같은 코인과 네트워크를 선택해 출금하면 됩니다.

바이낸스는 업비트의 계정주 확인 연동 거래소입니다. 100만원 이상을 보낼 때는 업비트에서 입금이 바로 반영되지 않고 '입금 대기' 상태가 된 뒤, 계정주 확인(추가 확인) 절차를 거쳐야 반영됩니다.

업비트는 원화 환산가 100만 원 이상의 디지털 자산 입금에 트래블룰 조건을 적용하고 있으며, 바이낸스는 현재 계정주 확인 연동 사업자 목록에 포함돼 있습니다.

보내기 전에 먼저 확인할 것

1. 업비트에서 해당 코인의 입금이 열려 있는지

바이낸스에서 먼저 출금하지 마세요. 가장 먼저 업비트에서 받을 코인의 입금 화면을 열어 현재 입금이 가능한지 확인하는 것이 안전합니다.

업비트 앱에서는 일반적으로 다음 경로로 확인할 수 있습니다.

입출금 → 받을 디지털 자산 검색 → 입금 → 입금 네트워크 확인

처음 입금하는 자산이라면 입금 주소를 생성해야 할 수도 있습니다. 업비트는 멀티체인을 지원하는 자산은 네트워크를 선택한 뒤 해당 네트워크의 입금 주소를 생성하도록 안내합니다.

2. 바이낸스와 업비트의 네트워크가 같은지

이 부분이 가장 중요합니다. 예를 들어 업비트에서 USDT 입금 네트워크로 Tron을 선택했다면 바이낸스에서도 USDT 출금 네트워크를 Tron(TRC20)으로 선택해야 합니다.

업비트가 지원하지 않는 네트워크를 바이낸스에서 선택하면 안 됩니다. 바이낸스 공식 문서 역시 단순히 수수료가 가장 싼 네트워크를 고르는 것이 아니라 받는 플랫폼이 지원하는 네트워크를 선택해야 한다고 명시하고 있습니다. 네트워크 선택 기준은 USDT & 네트워크 가이드를 참고하세요.

3. Tag 또는 MEMO가 필요한 자산인지

XRP 같은 자산은 단순히 입금 주소만 입력해서는 안 됩니다. 업비트 입금 화면에 입금 주소와 데스티네이션 태그 또는 MEMO 두 값이 나온다면 둘 다 복사해야 합니다.

태그가 필요한 자산에서 태그를 빼먹으면 블록체인 전송 자체는 성공했는데도 업비트 내 본인 계정으로 자동 반영되지 않는 상황이 생길 수 있습니다. 바이낸스도 일부 자산은 MEMO/태그가 필요하며 누락할 경우 자산 확인이 어려울 수 있다고 안내합니다.

1단계: 업비트에서 입금 주소를 확인합니다

업비트 앱을 열고 받을 자산을 선택합니다. 예를 들어 USDT를 보낸다면 입출금 → USDT → 입금으로 이동합니다.

여기서 바로 주소만 복사하지 말고 먼저 네트워크 이름을 확인하세요. USDT는 2026년 9월 30일 기준 업비트에서 다음 네트워크가 각각 별도로 표시됩니다.

  • Ethereum
  • Tron
  • Aptos
  • Kaia

예를 들어 Tron을 선택했다면 이후 바이낸스에서도 반드시 Tron 네트워크를 사용해야 합니다.

2단계: 바이낸스에서 출금 화면으로 이동합니다

바이낸스 앱에서는 계정 환경에 따라 다음 경로에서 암호화폐 출금을 진행합니다.

Assets → Overview/Spot → Send 또는 Withdraw Asset

화면 이름은 바이낸스 앱 버전과 계정 환경에 따라 조금씩 다를 수 있습니다. 출금할 자산을 선택한 뒤 외부 주소로 보내는 화면으로 이동하세요.

바이낸스의 공식 안내는 외부 주소 출금 시 다음 순서로 설명합니다.

  1. 출금 자산 선택
  2. 수취 주소 입력
  3. 네트워크 선택
  4. 출금 금액 입력
  5. 수수료와 실제 수령액 확인
  6. 출금 정보 재확인
  7. Passkey 또는 2FA로 인증

3단계: 업비트 주소를 바이낸스에 붙여넣습니다

앞에서 복사한 업비트 입금 주소를 바이낸스의 출금 주소란에 붙여넣습니다. 주소를 직접 한 글자씩 입력하는 것은 권장하지 않습니다. 업비트도 주소를 직접 입력하기보다 복사·붙여넣기 또는 QR 방식으로 입력할 것을 권장합니다. 주소 한 자리만 달라도 다른 곳으로 전송될 수 있기 때문입니다.

주소를 붙여넣은 뒤 다음 세 가지를 다시 확인하세요.

  • 코인 — USDT를 보내고 있는데 업비트에서 XRP 주소를 복사한 것은 아닌지 확인합니다.
  • 네트워크 — 업비트가 Tron이면 바이낸스도 Tron이어야 합니다.
  • 태그/MEMO — XRP처럼 별도 태그가 나온다면 주소와 함께 정확하게 입력합니다.

4단계: 바이낸스의 Address Origin 또는 수취처 정보를 확인합니다

여기가 기존 일반적인 송금 가이드와 다른 부분입니다. 바이낸스는 외부 출금 주소를 주소록에 등록하거나 일부 출금을 진행할 때 해당 주소가 어디에서 온 것인지 확인하는 Address Origin 정보를 요구할 수 있습니다. 바이낸스 공식 주소록 안내에서도 새 주소를 저장할 때 해당 주소가 거래소인지 지갑인지 출처를 지정할 수 있다고 설명합니다.

또한 바이낸스는 트래블룰 적용 지역의 출금 과정에서 beneficiary(수취인) 관련 추가 정보를 요구할 수 있다고 안내하고 있습니다. 요구되는 정보는 계정이 속한 바이낸스 법인과 지역에 따라 달라질 수 있습니다.

따라서 화면에 다음과 같은 항목이 나오면 실제 상황에 맞게 입력합니다.

  • 받는 곳이 거래소인지 개인지갑인지
  • 거래소 이름
  • 수취인 정보
  • beneficiary information

업비트로 본인 계정에 보내고 있다면 화면에 표시되는 안내에 따라 업비트와 본인 정보를 정확하게 선택·입력하세요. 모든 바이낸스 사용자가 동일한 질문지를 보게 되는 것은 아니므로, 특정 버튼이나 필드가 반드시 표시된다고 생각할 필요는 없습니다.

5단계: 금액과 실제 수령액을 확인합니다

출금 금액을 입력하면 바이낸스 화면에 보통 출금 금액, 네트워크 수수료, 실제 수령 예정 금액이 표시됩니다. 바이낸스 출금 수수료는 고정된 하나의 숫자가 아니며 자산과 네트워크에 따라 다르고 변경될 수 있으므로 실제 출금 화면에 표시되는 금액을 최종 기준으로 삼는 것이 가장 정확합니다.

예를 들어 USDT라도 Ethereum과 Tron의 출금 조건은 다를 수 있습니다. 따라서 '가장 싼 네트워크'를 먼저 선택하는 것이 아니라 업비트가 지원하는 네트워크 확인 → 바이낸스에서 동일 네트워크 선택 → 그 안에서 수수료 비교 순서가 안전합니다.

6단계: 출금 전 마지막으로 네 가지를 확인합니다

특히 처음 보내는 주소라면 큰 금액을 한 번에 보내기보다 소액 테스트 전송 후 정상 반영 여부를 확인하는 방법도 고려할 수 있습니다. 확인이 끝났다면 Passkey, OTP 또는 바이낸스가 요구하는 보안 인증을 완료합니다.

7단계: 바이낸스에서 출금 상태와 TXID를 확인합니다

출금 신청이 끝났다고 바로 업비트 잔고에 표시되는 것은 아닙니다. 먼저 바이낸스의 출금 내역을 확인하세요. 바이낸스 앱의 거래 내역 또는 Asset History에서 출금 진행 상황을 확인할 수 있습니다.

일반적으로 상태는 다음과 같이 이해하면 됩니다.

  • 아직 Processing이라면 — 바이낸스에서 아직 블록체인으로 전송을 완료하지 않은 상태일 수 있습니다. TXID가 아직 생성되지 않았다면 업비트보다 바이낸스 쪽 처리 상태를 먼저 확인하는 것이 맞습니다.
  • Completed이고 TXID가 있다면 — 바이낸스 측 출금이 블록체인으로 전송된 상태입니다. 이때는 TXID(Transaction ID / Transaction Hash)를 눌러 블록체인 탐색기에서 전송 성공 여부, 수취 주소, 전송 금액, 블록 확인 수, 네트워크를 확인할 수 있습니다.

즉, 바이낸스에서 Completed + 블록체인에서도 성공 → 그다음 업비트 상태를 확인하는 순서로 보는 것이 문제를 찾기 쉽습니다.

100만 원 이상이면 업비트에서 무엇이 달라지나요?

이 부분이 한국 사용자에게 가장 중요합니다. 업비트는 현재 원화 환산가 100만 원 이상의 디지털 자산 입출금에 트래블룰을 적용하고 있습니다. 자세한 기준은 트래블룰 가이드에서 확인하세요. 바이낸스는 업비트 공식 목록에서 계정주 확인 연동 가상자산사업자로 분류되어 있습니다.

따라서 바이낸스에서 본인의 업비트 계정으로 100만 원 이상이 입금되면 자동으로 잔고에 바로 반영되지 않고 입금대기 상태에서 추가확인 절차가 필요할 수 있습니다. 업비트는 계정주 확인 연동 사업자에서 들어온 100만 원 이상 입금의 경우, 입금대기 건의 추가확인을 진행한 뒤 송금인과 수취인이 동일인임이 확인되면 입금을 반영한다고 설명합니다.

100만 원 초과 여부는 송금 시점이 아니라 자산이 업비트 주소에 도착해 반영되는 시점의 업비트 실시간 시세로 판단됩니다. 보낼 때 100만 원 미만이었어도 전송 중 가격이 올라 100만 원을 넘으면 트래블룰 대상이 될 수 있습니다.

업비트에서 '입금대기'가 뜨면 이렇게 확인하세요

블록체인에서는 전송이 성공했는데 업비트 잔고가 늘지 않았다면 먼저 입출금 내역을 확인합니다. 100만 원 이상 트래블룰 대상 입금은 '입금대기'로 표시될 수 있습니다.

업비트 공식 안내에 따르면 입금대기 건은 추가확인 → 입금 신청 절차를 통해 확인할 수 있습니다. 바이낸스처럼 계정주 확인이 가능한 사업자에서 본인이 직접 보낸 자산이라면 계정주 확인 절차를 진행하고, 정상 확인되면 입금이 반영됩니다.

바이낸스와 업비트의 이름이 다르면 어떻게 되나요?

100만 원 이상 송금에서 자주 막히는 부분입니다. 계정주 확인의 핵심은 바이낸스 계정과 업비트 계정이 같은 사람의 계정인지 확인하는 것입니다. 따라서 해외 거래소의 KYC 정보와 업비트 회원정보가 다르게 등록돼 있으면 동일인 확인이 실패할 수 있습니다.

특히 확인할 항목은 다음과 같습니다.

  • 영문 이름 철자
  • 이름 순서
  • 생년월일
  • 계정 명의

문제가 생겼다고 해서 이름을 임의로 여러 번 변경하지 말고 먼저 두 거래소에 등록된 KYC 정보를 각각 확인하는 것이 좋습니다. 이미 입금대기 상태라면 업비트의 추가확인 절차를 먼저 진행하고, 계정주 확인이 되지 않을 경우 고객센터 안내에 따라 처리합니다. 자세한 확인·수정 순서는 영문 이름 불일치 해결 가이드를 참고하세요.

100만 원 미만이면 아무 확인도 없나요?

현재 업비트 공식 안내상 원화 환산가 100만 원 미만의 디지털 자산은 기존 방식으로 입금할 수 있습니다. 하지만 이것을 '100만 원 아래로 나눠 보내면 트래블룰을 피할 수 있다'는 의미로 이해하면 안 됩니다.

업비트는 100만 원 미만의 반복적인 입출금이 이상입출금으로 판단될 수 있다고 명시하고 있으며, 미신고 사업자 등 제한 대상과의 거래는 금액과 관계없이 제한될 수 있습니다. 따라서 임의로 금액을 쪼개는 방식이 아니라 정상적인 본인 계정 간 이전 절차를 따르는 것이 좋습니다.

가장 중요한 원칙은 바이낸스와 업비트 양쪽에서 동시에 지원되는 동일 네트워크를 선택하는 것입니다. 예를 들어 업비트에서 Tron 입금 주소를 생성했다면 바이낸스에서도 Tron을 선택합니다. 반대로 바이낸스에서 BSC, Solana 등 다른 USDT 네트워크가 보인다고 해서 아무 네트워크나 선택해서는 안 됩니다. 업비트 입금 화면에 실제 표시되는 네트워크를 기준으로 판단하세요.

바이낸스 출금은 됐는데 업비트에 안 들어올 때

다음 순서대로 확인하면 원인을 빠르게 좁힐 수 있습니다.

  1. 바이낸스가 Processing인지 확인 — 아직 Processing이라면 바이낸스 출금 처리가 끝날 때까지 확인합니다.
  2. TXID가 생성됐는지 확인 — Completed라면 TXID를 확인합니다.
  3. 블록체인에서 성공했는지 확인 — TXID를 블록체인 탐색기에서 열어 전송 성공 여부를 봅니다.
  4. 업비트 입금대기인지 확인 — 100만 원 이상이면 업비트에서 자동 반영되지 않고 추가확인이 필요할 수 있습니다.
  5. 네트워크가 같은지 확인 — 주소만 맞고 네트워크가 다르면 정상 입금이 되지 않을 수 있습니다.
  6. 태그/MEMO를 확인 — XRP 등 태그가 필요한 자산은 태그 누락 여부를 확인합니다.
  7. 업비트 입출금 점검을 확인 — 해당 자산의 입금이 일시 중단된 상태인지 공지를 확인합니다.

잘못된 네트워크로 보냈다면

이 경우에는 단순히 오래 기다린다고 해결되는 문제가 아닐 수 있습니다. 업비트는 동일한 자산이라도 네트워크가 다르면 입금 및 복구가 불가능할 수 있다고 경고합니다.

이미 전송했다면 다음 자료를 준비하세요.

  • 자산명
  • 보낸 수량
  • 보낸 네트워크
  • 바이낸스 출금 주소
  • 업비트 입금 주소
  • TXID
  • 전송 시간

그리고 바이낸스 출금은 성공했는지, 업비트가 해당 네트워크를 지원하는지 확인한 뒤 업비트 고객센터의 오입금/입금 문의 절차를 따릅니다.

바이낸스에서 업비트까지 얼마나 걸리나요?

정확히 몇 분이라고 고정할 수는 없습니다. 전송 시간은 블록체인 네트워크, 네트워크 혼잡, 필요한 블록 확인 수, 바이낸스 출금 처리, 업비트 입금 처리, 트래블룰 추가확인 여부에 따라 달라집니다.

따라서 단순히 '30분 지났는데 안 왔다'보다 바이낸스 상태 → TXID → 블록체인 상태 → 업비트 입금대기 순서로 확인하는 것이 정확합니다.

출금 수수료는 얼마인가요?

바이낸스 출금 수수료는 자산과 네트워크에 따라 달라집니다. 따라서 특정 숫자를 이 글에 고정해 놓기보다 출금 직전 바이낸스 화면의 Network Fee를 확인하는 것이 가장 정확합니다.

비용확인 방법
바이낸스 출금 수수료바이낸스 출금 화면
블록체인 네트워크 비용선택 네트워크에 포함

실제 수령량바이낸스 출금 확인 화면

수수료가 낮다는 이유만으로 업비트가 지원하지 않는 네트워크를 선택해서는 안 됩니다.

자주 묻는 질문

바이낸스에서 업비트로 바로 보낼 수 있나요?
가능합니다. 업비트는 바이낸스를 계정주 확인 연동 가상자산사업자로 분류하고 있습니다. 다만 지원되는 자산과 네트워크를 사용해야 하며, 100만 원 이상 입금에서는 추가확인이 필요할 수 있습니다.
100만 원 이상 보내면 자동으로 입금되나요?
바이낸스에서 들어오는 100만 원 이상 입금은 업비트에서 입금대기 상태가 되고 계정주 추가확인이 필요한 경우가 있습니다. 추가확인 후 동일인 계정임이 확인되면 반영됩니다.
USDT는 TRC20으로 보내면 되나요?
업비트는 현재 USDT의 Tron 네트워크를 지원하지만 Ethereum, Aptos, Kaia도 지원합니다. 무조건 TRC20을 선택하는 것이 아니라 업비트에서 선택한 네트워크와 바이낸스 출금 네트워크를 동일하게 맞추는 것이 핵심입니다.
바이낸스에 업비트 선택 화면이 안 나오는데 문제가 있나요?
반드시 모든 계정에서 동일한 수취 거래소 선택 화면이 표시되는 것은 아닙니다. 바이낸스의 트래블룰 관련 추가 질문은 계정 지역과 적용 규정에 따라 달라질 수 있습니다. 주소·네트워크와 화면에 요구되는 beneficiary/address-origin 정보를 정확하게 입력하면 됩니다.
XRP는 주소만 입력하면 되나요?
아닙니다. 업비트 입금 화면에서 데스티네이션 태그가 표시된다면 주소와 태그를 모두 바이낸스 출금 화면에 입력해야 합니다.
바이낸스에서는 Completed인데 업비트에 없습니다.
먼저 바이낸스의 TXID를 확인하고 블록체인에서 전송이 성공했는지 확인하세요. 성공했다면 업비트의 입출금 내역에서 입금대기 여부를 확인합니다. 100만 원 이상 입금이라면 추가확인이 필요한 경우가 있습니다.
100만 원 미만으로 나눠 보내면 되나요?
트래블룰 회피 목적으로 반복해서 소액으로 나누는 것은 권장되지 않습니다. 업비트는 100만 원 미만의 반복 입출금도 이상입출금으로 판단되어 반려될 수 있다고 안내합니다.
