바이낸스에서 업비트로 코인 보내는 방법

바이낸스에서 업비트로 코인을 보내려면 업비트에서 입금 주소를 확인한 뒤, 바이낸스 출금 화면에서 같은 코인과 네트워크를 선택해 출금하면 됩니다.

바이낸스는 업비트의 계정주 확인 연동 거래소입니다. 100만원 이상을 보낼 때는 업비트에서 입금이 바로 반영되지 않고 '입금 대기' 상태가 된 뒤, 계정주 확인(추가 확인) 절차를 거쳐야 반영됩니다.

빠른 답변
  • 가장 중요한 건 네트워크를 양쪽에서 동일하게 맞추는 일입니다. 업비트 USDT 입금은 Ethereum·Tron·Aptos·Kaia 네트워크를 지원합니다.
  • 바이낸스는 업비트의 계정주 확인 연동 거래소라서, 100만원 이상은 입금 대기 후 추가 확인을 거쳐야 반영됩니다.
  • XRP처럼 데스티네이션 태그(Tag)가 필요한 코인은 태그까지 정확히 입력해야 합니다.
  • 바이낸스와 업비트의 성명·생년월일이 일치해야 100만원 이상 입금이 정상 반영됩니다.

먼저 확인할 것

  • 양쪽 계정주 일치 — 업비트와 바이낸스에 등록된 성명·생년월일이 동일해야 합니다. 이름 철자가 다르면 100만원 이상 입금이 반영되지 않거나 반환될 수 있습니다.
  • 보낼 코인과 네트워크 — 업비트가 지원하는 네트워크를 미리 확인합니다. USDT라면 업비트가 지원하는 네트워크(Ethereum·Tron·Aptos·Kaia) 중 하나로 받습니다.
  • 태그 필요 여부 — XRP 등은 데스티네이션 태그(Tag)가 필수입니다.
  • 바이낸스 KYC 완료 — 바이낸스에서 출금하려면 신원 인증(KYC)을 완료한 계정이어야 합니다.
  • 100만원 판단 시점 확인 — 입금 금액은 바이낸스 출금 시점이 아니라, 자산이 업비트 주소에 도착한 시점의 업비트 원화 시세로 계산합니다.

전체 과정 한눈에 보기

1. 입금 주소 확인

업비트에서 받을 코인과 네트워크를 고르고 입금 주소(필요 시 태그)를 복사합니다.

2. 코인 준비

바이낸스에서 보낼 코인(USDT·XRP·TRX 등)을 준비합니다.

3. 네트워크 맞추기

바이낸스 출금 네트워크를 업비트와 동일하게 선택합니다.

4. 주소·태그 입력

복사한 주소와 태그를 바이낸스 출금 화면에 붙여넣습니다.

5. 수취인 정보

100만원 이상이면 수취 거래소를 'Upbit'로 선택하고 수취인 정보를 확인합니다.

6. 출금 신청

바이낸스 인증을 완료하면 출금이 전송됩니다.

7. 입금 대기 · 계정주 확인

업비트에서 입금 대기 건의 추가 확인을 진행하면 반영됩니다.

1단계: 업비트 입금 주소 확인

업비트 앱이나 웹에서 자산 → 해당 코인 → 입금으로 들어갑니다. 받을 코인을 고르고, 네트워크를 선택한 뒤 입금 주소를 복사하세요. 이때 선택한 네트워크를 기억해 둬야 합니다.

리플(XRP)처럼 데스티네이션 태그(Tag)가 필요한 코인은 주소와 함께 태그까지 복사해 두세요. 태그를 빼먹으면 입금이 내 계정에 붙지 않고 반환 처리되거나 지연될 수 있습니다. 입금 전 상태는 자산 → 해당 코인 → 입출금 현황에서 확인할 수 있습니다. 자세한 입금 정보 입력 방법은 업비트 고객센터의 입금 정보 입력 안내를 참고하세요.

2단계: 바이낸스에서 출금 준비

바이낸스에서 지갑 → 출금(Withdraw)으로 이동해 같은 코인을 선택합니다. 전송용으로는 수수료가 낮고 도착이 빠른 코인이 유리합니다.

  • 리플(XRP) — 전송이 빠르고 수수료가 낮지만, 데스티네이션 태그 입력이 필수입니다.
  • 트론(TRX) — 전송 속도가 빠르고 출금 수수료가 비교적 낮은 편입니다.
  • USDT — 업비트는 USDT 입출금에 Ethereum·Tron·Aptos·Kaia 네트워크를 지원합니다. 수수료와 속도 면에서 Tron(TRC-20)이 무난한 선택지입니다.

비트코인(BTC)이나 이더리움(ETH)은 전송 수수료가 상대적으로 높고 속도가 느릴 수 있어, 단순 이동 목적에는 비효율적입니다.

3단계: 네트워크를 반드시 맞추세요

바이낸스 출금 화면에서 네트워크를 고를 때 1단계에서 업비트가 선택한 네트워크와 동일하게 맞춥니다.

업비트는 2026년 9월 현재 USDT 입출금에 Ethereum, Tron, Aptos, Kaia 네트워크를 지원합니다. 바이낸스에서 USDT를 보낼 때는 업비트 입금 화면에 실제 표시되는 네트워크 중 하나를 선택하고, 바이낸스 출금 화면에서도 동일한 네트워크를 선택하세요. BSC(BEP-20), Solana 등 업비트 USDT 입금 화면에 표시되지 않는 네트워크로 보내면 입금이 반영되지 않거나 복구가 어려울 수 있습니다. 네트워크 선택 기준은 USDT & 네트워크 가이드를 참고하세요.

네트워크 불일치는 코인 유실의 가장 큰 원인입니다. 주소 형식이 같아 보여도 체인이 다르면 찾기 어려울 수 있으니, 출금 버튼을 누르기 전에 반드시 한 번 더 확인하세요.

4단계: 트래블룰 확인

바이낸스 출금 시 수취 거래소를 'Upbit'로 선택합니다. 트래블룰 절차는 금액에 따라 달라집니다. 업비트의 입출금 가능 가상자산사업자(VASP) 목록은 업비트 고객센터에서 확인할 수 있습니다.

  • 100만원 이상 — 업비트에서 입금이 바로 반영되지 않고 '입금 대기' 상태가 됩니다. 바이낸스는 업비트의 계정주 확인 연동 거래소이므로, 입금 대기 건의 추가 확인(계정주 확인)을 진행해야 입금이 반영됩니다. 이때 바이낸스 계정과 업비트 계정의 성명·생년월일이 일치해야 합니다.
  • 100만원 미만 — 현재(2026년 9월) 트래블룰 계정주 추가 확인 대상은 아닙니다. 다만 네트워크, 입금처, 지원 여부 및 업비트의 이상거래 모니터링 정책은 그대로 적용되므로, 미신고 가상자산사업자나 등록되지 않은 개인지갑을 통한 입금은 금액과 관계없이 반영이 제한될 수 있습니다.

100만원 판단 기준: 100만원 기준은 바이낸스에서 출금한 시점이 아니라, 자산이 업비트 주소에 도착한 시점의 업비트 원화 시세를 기준으로 판단합니다. 출금 당시 100만원 미만이었더라도 도착 시점 가격이 올라 100만원을 넘으면 계정주 추가 확인 대상이 될 수 있습니다.

참고: 금융위원회는 2026년 8월 트래블룰의 현행 100만원 기준을 폐지하고 정보제공 의무를 전체 거래로 확대하는 시행령 개정안을 의결했습니다. 관련 규정은 공포 후 6개월이 지난 날부터 시행될 예정입니다. 따라서 시행 이후에는 현재의 '100만원 미만 / 이상' 구분이 달라질 수 있습니다. 이 가이드는 2026년 9월 기준이며, 실제 시행 시 업비트 정책에 맞춰 업데이트합니다.

5단계: 입금 대기 후 계정주 확인

100만원 이상 입금은 업비트에서 자동으로 반영되지 않고 '입금 대기'로 표시됩니다. 이때 다음 순서로 계정주 확인을 진행하세요.

  1. 입출금 → 입금된 디지털 자산 선택 → 입출금내역 탭으로 이동합니다.
  2. 입금 대기 건의 '추가 확인이 필요한 입금 건입니다' 버튼을 선택합니다.
  3. 입금정보 확인 → 거래소를 통해 입금된 경우 → 거래소 선택에서 바이낸스를 선택합니다.
  4. 본인 계정 확인을 진행하면, 업비트 계정과 바이낸스 계정의 성명·생년월일 일치 여부를 확인한 뒤 입금을 반영합니다.

이름·생년월일이 일치하지 않으면 입금이 반영되지 않고 반환 절차가 필요할 수 있습니다. 출금 전에 양쪽 계정의 성명·생년월일을 먼저 확인하는 것이 가장 확실합니다.

수수료는 얼마인가요?

항목내용
바이낸스 출금 수수료코인·네트워크별로 다르며 자주 변경됩니다. 출금 전 바이낸스 출금 화면에서 최종 수수료를 확인하세요.
업비트 입금 수수료무료입니다.
네트워크 수수료체인별로 다릅니다. XRP·TRX는 낮은 편, BTC·ETH는 상대적으로 높습니다.

얼마나 걸리나요?

보통 수분~수십 분 안에 도착하지만, 네트워크가 혼잡하면 더 걸릴 수 있습니다. 100만원 이상 입금은 블록체인 전송 이후 업비트의 입금 대기 → 계정주 확인 절차가 추가로 필요해, 확인을 진행하기 전까지는 반영되지 않습니다. 도착 여부는 시간이 아니라 블록체인 컨펌(확정) 수를 기준으로 판단하는 게 정확합니다.

입금이 안 들어올 때

  • 입금 대기 확인 — 100만원 이상은 업비트 입출금내역 → 입금 대기 건 → 추가 확인을 진행해야 반영됩니다.
  • 계정주 불일치 — 바이낸스와 업비트의 성명·생년월일이 같은지 확인합니다. 다르면 반환 절차가 필요할 수 있습니다.
  • 네트워크 불일치 — 바이낸스와 업비트가 같은 네트워크인지 다시 확인합니다. 업비트 USDT는 Ethereum·Tron·Aptos·Kaia 네트워크를 지원합니다.
  • 태그·MEMO 누락 — XRP 등 태그가 필요한 코인은 태그가 빠지지 않았는지 확인합니다.
  • TXID 확인 — 출금이 실제로 전송됐는지 블록체인 탐색기에서 TXID(트랜잭션 해시)로 먼저 확인합니다.
  • 업비트 점검 여부 — 해당 코인의 입금이 일시 중단됐는지 업비트 공지를 확인합니다.

입금이 1시간 이상 지연되거나 블록체인에서는 확인되는데 업비트에 반영되지 않는다면, TXID를 준비해 업비트 고객센터에 문의하세요.

자주 묻는 질문

바이낸스에서 업비트로 100만원 이상 보내면 바로 입금되나요?
바로 반영되지 않고 업비트에서 '입금 대기' 상태가 됩니다. 입출금내역에서 해당 건의 '추가 확인'을 선택해 계정주 확인(성명·생년월일 일치 확인)을 진행해야 입금이 반영됩니다.
100만원 미만이면 트래블룰 확인 없이 바로 입금되나요?

업비트에서 USDT를 어떤 네트워크로 받아야 하나요?

바이낸스와 업비트의 이름 표기가 다르면 어떻게 되나요?
