OKX에서 빗썸으로 코인 보내는 방법

OKX에서 빗썸으로 코인을 보내려면 빗썸에서 입금 주소를 확인한 뒤, OKX 출금 화면에서 같은 코인과 네트워크를 선택해 출금하면 됩니다.

OKX는 빗썸의 트래블룰 솔루션 CODE 연동 해외 VASP입니다. 해외 거래소에서 빗썸으로 100만원 이상 입금하면 자동 반영되지 않고 '입금신청 대기' 상태가 되며, 입금 신청 후 송금 거래소의 출금 내역과 회원정보 등 증빙자료를 제출해 심사를 받아야 합니다.

빠른 답변
  • 가장 중요한 건 네트워크를 양쪽에서 동일하게 맞추는 일입니다. 빗썸 USDT 입금은 Tron·Ethereum·Kaia·Aptos 네트워크를 지원합니다.
  • OKX는 빗썸의 CODE 연동 해외 VASP입니다. 해외 거래소에서 100만원 이상 입금하면 자동 반영되지 않고 입금신청 대기 상태가 되며, 입금 신청 후 증빙자료를 제출해야 반영됩니다.
  • 증빙자료는 출금 내역(TXID·수량·빗썸 주소)과 회원정보가 확인되는 편집 없는 전체 화면을 제출합니다.
  • 시드문구·개인키·복구문구는 절대 제출하면 안 됩니다. 이를 요구하는 곳은 정상 경로가 아닙니다.

먼저 확인할 것

  • 양쪽 계정주 일치 — OKX와 빗썸에 등록된 성명이 동일해야 합니다. 이름 표기가 다르면 입금 신청 심사에서 확인이 어려울 수 있습니다.
  • 보낼 코인과 네트워크 — 빗썸이 지원하는 네트워크를 미리 확인합니다. USDT라면 빗썸이 지원하는 네트워크(Tron·Ethereum·Kaia·Aptos) 중 하나로 받습니다.
  • 태그 필요 여부 — XRP 등은 데스티네이션 태그(Tag)가 필수입니다.
  • OKX KYC 완료 — OKX에서 출금하려면 신원 인증(KYC)을 완료한 계정이어야 합니다.
  • 100만원 이상 증빙 준비 — 100만원 이상 보낼 예정이면, 나중에 제출할 출금 내역 화면을 미리 캡처해 두면 편합니다.

전체 과정 한눈에 보기

1. 입금 주소 확인

2. 코인 준비

OKX에서 보낼 코인(USDT·XRP·TRX 등)을 준비합니다.

3. 네트워크 맞추기

OKX 출금 네트워크를 빗썸과 동일하게 선택합니다.

4. 주소·태그 입력

복사한 주소와 태그를 OKX 출금 화면에 붙여넣습니다.

5. 출금 신청

OKX 인증을 완료하면 출금이 전송됩니다.

6. 입금신청 대기 · 증빙 제출

100만원 이상은 빗썸에서 입금신청 대기 상태가 됩니다. 입금 신청 후 증빙자료를 제출하면 심사 후 반영됩니다.

1단계: 빗썸 입금 주소 확인

빗썸 앱이나 웹에서 입출금 → 해당 코인 → 입금으로 들어갑니다. 받을 코인을 고르고, 네트워크를 선택한 뒤 입금 주소를 복사하세요. 이때 선택한 네트워크를 기억해 둬야 합니다.

리플(XRP)처럼 데스티네이션 태그(Tag)가 필요한 코인은 주소와 함께 태그까지 복사해 두세요. 태그를 빼먹으면 입금이 내 계정에 붙지 않고 반환 처리되거나 지연될 수 있습니다. 입금 전 상태는 입출금 → 해당 코인 → 입출금 현황에서 확인할 수 있습니다.

2단계: OKX에서 출금 준비

OKX 앱이나 웹에서 자산(Assets) → 출금(Withdraw)으로 이동해 같은 코인을 선택합니다. 전송용으로는 수수료가 낮고 도착이 빠른 코인이 유리합니다.

  • 리플(XRP) — 전송이 빠르고 수수료가 낮지만, 데스티네이션 태그 입력이 필수입니다.
  • 트론(TRX) — 전송 속도가 빠르고 출금 수수료가 비교적 낮은 편입니다.
  • USDT — 빗썸은 USDT 입출금에 Tron·Ethereum·Kaia·Aptos 네트워크를 지원합니다. Tron(TRC-20)은 OKX와 빗썸이 모두 지원하는 네트워크 중 하나이므로, 실제 출금 수수료와 처리 속도를 비교한 뒤 선택할 수 있습니다.

비트코인(BTC)이나 이더리움(ETH)은 전송 수수료가 상대적으로 높고 속도가 느릴 수 있어, 단순 이동 목적에는 비효율적입니다.

3단계: 네트워크를 반드시 맞추세요

OKX 출금 화면에서 네트워크를 고를 때 1단계에서 빗썸이 선택한 네트워크와 동일하게 맞춥니다.

빗썸은 2026년 9월 현재 USDT 입출금에 Tron, Ethereum, Kaia, Aptos 네트워크를 지원합니다. OKX에서 USDT를 보낼 때는 OKX 출금 화면에 실제 표시되는 네트워크 중에서, 빗썸이 지원하는 네트워크와 동일한 것을 선택하세요. 빗썸 입금 화면에 표시되지 않는 네트워크로 보내면 입금이 반영되지 않거나 복구가 어려울 수 있습니다. 네트워크 선택 기준은 USDT & 네트워크 가이드를 참고하세요.

네트워크 불일치는 코인 유실의 가장 큰 원인입니다. 주소 형식이 같아 보여도 체인이 다르면 찾기 어려울 수 있으니, 출금 버튼을 누르기 전에 반드시 한 번 더 확인하세요.

4단계: 트래블룰 확인

트래블룰 절차는 금액에 따라 달라집니다. 빗썸의 입금 대기 안내는 빗썸 고객센터에서 확인할 수 있습니다.

  • 100만원 이상 — 해외 거래소인 OKX에서 빗썸으로 100만원 이상 입금하면 자동 반영되지 않고 '입금신청 대기' 상태가 됩니다. 입출금 내역에서 해당 건의 입금 신청을 진행하고, 출금 내역과 회원정보 등 증빙자료를 제출하면 빗썸 심사 후 반영됩니다.
  • 100만원 미만 — 현재(2026년 9월) 트래블룰 정보제공 의무 대상은 아닙니다. 다만 네트워크, 입금처, 지원 여부 및 빗썸의 이상거래 모니터링 정책은 그대로 적용되므로, 미신고 가상자산사업자나 등록되지 않은 개인지갑을 통한 입금은 금액과 관계없이 반영이 제한될 수 있습니다.

참고: 금융위원회는 2026년 8월 트래블룰의 현행 100만원 기준을 폐지하고 정보제공 의무를 전체 거래로 확대하는 시행령 개정안을 의결했습니다. 관련 규정은 공포 후 6개월이 지난 날부터 시행될 예정입니다. 따라서 시행 이후에는 현재의 '100만원 미만 / 이상' 구분이 달라질 수 있습니다. 이 가이드는 2026년 9월 기준이며, 실제 시행 시 빗썸 정책에 맞춰 업데이트합니다.

5단계: 입금신청 대기 후 증빙 제출

OKX에서 보낸 코인이 네트워크에 도착해도, 해외 거래소에서 100만원 이상 입금한 경우 빗썸은 자동으로 반영하지 않고 '입금신청 대기' 상태로 두고 별도의 입금 신청을 요구합니다.

반영 절차는 다음과 같습니다.

  1. 빗썸 입출금 내역에서 해당 입금 건을 확인합니다.
  2. 입금신청 대기 건을 선택해 입금 신청을 진행합니다.
  3. 요구되는 증빙자료를 제출합니다.
  4. 빗썸이 심사한 뒤 입금이 반영됩니다.

제출하는 증빙자료는 다음과 같은 화면입니다.

  • 출금 내역 화면 — OKX에서 출금한 일시, 가상자산명, 수량, TXID, 빗썸 입금 주소가 모두 보이는 화면
  • 회원정보 화면 — 빗썸과 동일한 이름·이메일·휴대폰번호 중 하나가 확인되는 OKX 마이페이지/회원정보 화면

화면은 편집하지 않은 전체 화면으로 캡처해 제출해야 합니다. 제출 경로는 빗썸 앱 입출금 → 내역 → 입금신청 대기 내역 → 입금신청, PC는 지갑관리 → 거래내역 → 입출금 내역 → 입금신청 대기 내역 → 입금신청입니다.

시드문구·개인키·복구문구는 절대 제출하면 안 됩니다. 빗썸 고객센터 직원이라도 이를 요구한다면 정상적인 요청이 아니므로 응하지 말고, 반드시 빗썸 공식 앱·홈페이지의 입금신청 화면에서만 서류를 제출하세요.

얼마나 걸리나요?

보통 수분~수십 분 안에 도착하지만, 네트워크가 혼잡하면 더 걸릴 수 있습니다. 100만원 이상 해외 거래소 입금은 블록체인 전송 이후 입금신청 대기 → 입금 신청·증빙 제출 → 심사 절차가 추가로 필요해, 입금 신청을 진행하기 전까지는 반영되지 않습니다. 도착 여부는 시간이 아니라 블록체인 컨펌(확정) 수를 기준으로 판단하는 게 정확합니다.

입금이 안 들어올 때

  • 입금신청 대기 확인 — 100만원 이상 해외 거래소 입금은 빗썸 입출금 내역 → 입금신청 대기 건 → 입금 신청을 진행해야 반영됩니다.
  • 계정주 불일치 — OKX와 빗썸의 성명이 일치하는지 확인합니다. 다르면 심사에서 확인이 어려울 수 있습니다.
  • 증빙서류 누락 — 출금 내역 화면에 TXID·수량·빗썸 주소가 모두 보이는지, 회원정보 화면이 편집되지 않았는지 확인합니다.
  • 네트워크 불일치 — OKX와 빗썸이 같은 네트워크인지 다시 확인합니다. 빗썸 USDT는 Tron·Ethereum·Kaia·Aptos 네트워크를 지원합니다.
  • 태그·MEMO 누락 — XRP 등 태그가 필요한 코인은 태그가 빠지지 않았는지 확인합니다.
  • TXID 확인 — 출금이 실제로 전송됐는지 블록체인 탐색기에서 TXID(트랜잭션 해시)로 먼저 확인합니다.

블록체인에서는 전송 완료로 확인되는데 빗썸에 계속 반영되지 않는다면, TXID를 준비해 빗썸 고객센터에 문의하세요.
